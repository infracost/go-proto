# go-proto

Go wrapper types and utilities for working with Infracost protocol buffer types from [infracost/proto](https://github.com/infracost/proto).

## Packages

| Package | Description |
|---------|-------------|
| [address](pkg/address) | Terraform address modeling and manipulation |
| [diagnostic](pkg/diagnostic) | Error and warning reporting utilities |
| [flag](pkg/flag) | Bitfield flags for value origin tracking |
| [rat](pkg/rat) | Arbitrary-precision rational numbers |
